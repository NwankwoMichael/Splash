# Splash 📸

Welcome to **Splash**, a modern and responsive photography portfolio website designed to showcase the artistry of Michael Nwankwo. With a clean layout and intuitive navigation, Splash transforms moments into masterpieces.

## 🌟 Features

- Elegant landing page with hero section and tagline
- Dynamic gallery showcasing portraits, weddings, and outdoor shoots
- About section highlighting Michael's story and approach
- Contact form for inquiries and bookings
- Responsive design for mobile, tablet, and desktop
- Privacy and security policy pages

## 🚀 Getting Started

To run Splash locally:

```bash
git clone https://github.com/your-username/splash.git
cd splash
open index.html
```
Or simply open Splash.html in your browser.
